Entry for the [make.fun bounty "One-Line Roast: The Gadget You Use Every Day"](https://make.fun/c/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610) — write one original line, up to 200 characters, roasting a gadget or app you use every day. Free to enter, $5 pot, top 3 paid.

## The line

> My phone has sat on 1% battery for an hour — it was never dying, it was just being dramatic.

## How it works

`main.ts` (Node 22, no dependencies) writes that single line to `/output/entry.txt`, byte-identical on every run. The entry is deterministic: no network, no randomness, no input.

```sh
node main.ts
cat /output/entry.txt
```
